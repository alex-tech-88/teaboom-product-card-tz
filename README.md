# Карточка товара Teaboom.ru

Тестовое задание: верхняя часть карточки товара [«Ананасовый улун»](https://teaboom.ru/product/ananasovij-ulun) — фото, название, категория, выбор фасовки, артикул, цена, старая цена, кнопка «В корзину» и описание.

HTML5, CSS и JavaScript без фреймворков и сборки.

## Запуск

Сборка и установка зависимостей не нужны. Подойдёт любой из способов ниже.

### 1. Открыть файл напрямую

Дважды кликните по `index.html` или выполните команду в папке проекта:

| ОС | Команда |
|---|---|
| macOS | `open index.html` |
| Windows | `start index.html` |
| Linux | `xdg-open index.html` |

### 2. Live Server в VS Code

1. Установите расширение [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer).
2. Откройте папку проекта в VS Code.
3. Кликните правой кнопкой по `index.html` → **Open with Live Server** или нажмите **Go Live** в строке состояния.

Страница откроется на `http://127.0.0.1:5500/index.html` и будет обновляться при сохранении файлов. Способ одинаковый для macOS, Windows и Linux.

### 3. Локальный сервер из терминала

Запустите в папке проекта и откройте http://localhost:8000.

| ОС | Команда |
|---|---|
| macOS, Linux | `python3 -m http.server 8000` |
| Windows | `py -m http.server 8000` |
| Любая ОС с Node.js | `npx serve -l 8000` |

Остановить сервер — `Ctrl+C`.

Шрифт Open Sans подключается из Google Fonts, без интернета страница покажется системным шрифтом.

## Структура

```
index.html      разметка карточки
css/style.css   стили
js/main.js      фасовки и цена, галерея, вкладки, избранное
img/            фото товара в нескольких размерах (JPEG и WebP)
```

## Что сделано

**Фасовки.** Сделаны radio-кнопками внутри `<fieldset>`, поэтому работают с клавиатуры (Tab, стрелки) и в экранных чтилках. Цена, старая цена и артикул хранятся в `data-атрибутах` каждой фасовки. При переключении скрипт обновляет цену, старую цену и артикул, а выбранная фасовка подсвечивается.

**Цена.** Форматируется через `Intl.NumberFormat`: `326,40 ₽`, `1 432 ₽`. Под цену отведена колонка фиксированной ширины, поэтому кнопка «В корзину» не сдвигается при смене фасовки. Изменение цены скринридерами (`aria-live`).

**Кнопка «В корзину».** Есть обычное состояние, наведение, фокус с клавиатуры и нажатие. Корзина не подключена, отправка формы отключена.

**Адаптивность** — 375, 768 и 1440 px:

- до 768 px — одна колонка;
- от 768 px — фото и информация в две колонки;
- блок цены зависит от ширины своей колонки (container query): если цена и кнопка не помещаются в строку, кнопка уходит под цену и растягивается на всю ширину.

**Изображения.** Используются `<picture>`, `srcset` и `sizes` с вариантами 400, 640 и 970 px в WebP с запасным JPEG. Телефон не загружает фото для десктопа. У изображений заданы `width` и `height`, чтобы вёрстка не прыгала при загрузке.

**Семантика и доступность:**

- хлебные крошки — `<nav>` + `<ol>`;
- карточка — `<article>`;
- вкладки «Описание / Свойства / Отзывы» — `<section>` с ролями `tablist`, `tab`, `tabpanel`;
- свойства товара — список `<dl>`;
- видимый фокус у всех интерактивных элементов;
- контраст текста и фона не ниже 4,5:1 (WCAG AA).

**Микроразметка.** Используется schema.org `Product` и `Offer`: название, категория, фото, артикул, цена, валюта и наличие. Цена в разметке тоже обновляется при смене фасовки.

**Стилистика** — по мотивам teaboom.ru: фон с узором из чашек, красные цены, салатовая кнопка корзины, чёрная панель вкладок, кремовый блок описания, Open Sans.

## Отличия от teaboom.ru

- **Кнопка «В корзину» и выбор фасовки.** На сайте у каждой строки фасовки своя кнопка корзины, а выбрать фасовку нельзя. По ТЗ при переключении фасовки должны меняться цена, старая цена, артикул и выбранное состояние. Поэтому строки фасовок стали выбором (radio), а под ними добавлен блок с артикулом, ценой, старой ценой и одной кнопкой «В корзину» для выбранной фасовки.
- **Описание и свойства.** Текст немного видоизменён для лучшей читаемости: описание разбито на абзацы с подзаголовками «Вкус» и «Полезные свойства», полезные свойства оформлены списком, свойства — таблицей «название — значение».

## Сверх задания

- **Галерея.** Миниатюры и просмотр на весь экран через `<dialog>`: стрелки, листание клавиатурой и свайпом, закрытие по Esc или клику на фон. На сайте у товара одно фото, поэтому и здесь одна миниатюра; стрелки и счётчик появляются автоматически, если добавить в `.gallery__thumbs` ещё фото.
- **Вкладки.** «Описание», «Свойства» и «Отзывы», как на сайте. Переключение мышью и с клавиатуры по паттерну WAI-ARIA: стрелки ←/→, Home, End.
- **Избранное.** Кнопка-сердечко (`aria-pressed`), состояние сохраняется в `localStorage`.
- Ссылка «оставить отзыв» открывает вкладку «Отзывы» и прокручивает к ней. Формы отзыва нет — вкладка-заглушка.
